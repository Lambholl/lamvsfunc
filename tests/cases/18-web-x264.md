# 18 web-x264

## Purpose

Web + x264 single-language path. Subtitle is burned in via VS, MP4Box
muxes with chapter. Web counterpart of case 14. **This is the first
case that exercises a non-HEVC encode on a Web source** — Web reuses
the ffmpeg-copy m4a directly for the 264 mux (no qaac re-extraction).

## Prerequisites

- Tools on PATH: `ffmpeg`, `x264`, `MP4Box`.
- Fixtures: `sample.mkv`, `sample.sc.ass`, `sample.txt`.

## Setup

Automatic. The script calls
`case_lib.prepare("18", ["sample.mkv", "sample.sc.ass", "sample.txt"])`.

## Execute

```powershell
& "F:\Encode tools\VS-Portable-R65\python.exe" tests\scripts\case_18.py
```

## Verify

- Exit code: `0`.
- Output `tests\.tmp\18\sample.sc.mp4` exists.
- mkvmerge identify on the mp4: 2 tracks (h264 + AAC) + chapter present.
  ```powershell
  python tests\scripts\verify_mkv.py "tests\.tmp\18\sample.sc.mp4" `
      tracks.length tracks[0].codec tracks[1].codec chapters.length
  # tracks.length: 2
  # tracks[0].codec: ... MPEG-4p10/AVC/H.264 ...
  # tracks[1].codec: AAC
  # chapters.length: 1
  ```
- Log:
  ```powershell
  python tests\scripts\verify_log.py "tests\.tmp\18\run.log" `
      --must "RP Checker complete for CHS" `
      --must-not "qaac" `
      --must-not "broken frame found"
  ```
  The `qaac` must-not check confirms that Web sources do not invoke
  qaac for the 264 path (Web reuses the ffmpeg-copy m4a).

## Cleanup

```powershell
if ($LASTEXITCODE -eq 0) { Remove-Item -Recurse -Force "tests\.tmp\18" }
```
