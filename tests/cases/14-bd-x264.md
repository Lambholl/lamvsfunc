# 14 bd-x264

## Purpose

BD + x264 single-language path. Subtitle is burned in via VS, MP4Box
muxes with chapter. Verifies the 264 branch end-to-end.

## Prerequisites

- Tools on PATH: `eac3to`, `qaac64`, `ffmpeg`, `x264`, `MP4Box`.
- Fixtures: `sample.m2ts`, `sample.sc.ass`, `sample.txt`.

## Setup

Automatic. The script calls
`case_lib.prepare("14", ["sample.m2ts", "sample.sc.ass", "sample.txt"])`.

## Execute

```powershell
& "F:\Encode tools\VS-Portable-R65\python.exe" tests\scripts\case_14.py
```

## Verify

- Exit code: `0`.
- Output `tests\.tmp\14\sample.sc.mp4` exists.
- mkvmerge identify on the mp4: 2 tracks (h264 + AAC) + chapter present.
  ```powershell
  python tests\scripts\verify_mkv.py "tests\.tmp\14\sample.sc.mp4" `
      tracks.length tracks[0].codec tracks[1].codec chapters.length
  # tracks.length: 2
  # tracks[0].codec: ... MPEG-4p10/AVC/H.264 ...
  # tracks[1].codec: AAC
  # chapters.length: 1
  ```
- Log:
  ```powershell
  python tests\scripts\verify_log.py "tests\.tmp\14\run.log" `
      --must "RP Checker complete for CHS" `
      --must-not "broken frame found"
  ```

## Cleanup

```powershell
if ($LASTEXITCODE -eq 0) { Remove-Item -Recurse -Force "tests\.tmp\14" }
```
